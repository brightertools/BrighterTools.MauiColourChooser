# Security

Please report suspected vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/brightertools/BrighterTools.MauiColourChooser/security/advisories/new) when enabled.

If private reporting is unavailable, open an issue asking for a private contact without including exploit details, sensitive data or credentials. The maintainer should enable private vulnerability reporting in repository settings.

Include affected versions, a minimal reproduction and likely impact. The latest published version is the maintenance target; older versions may require upgrading. No response-time or long-term-support guarantee is implied.

The component does not capture the screen, store user settings, access a clipboard or request network access. Native rendering and MAUI dependencies still need normal dependency maintenance.
